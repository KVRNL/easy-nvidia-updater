# Easy NVidia Updater

**Keeps your NVIDIA drivers up to date, automatically - by [KVRNL](https://kvrnl.io).**

A lightweight background app that lives in your system tray. It auto-detects your NVIDIA GPU (no
model-picking), checks NVIDIA for new drivers on a schedule, and either installs them silently or
notifies you first - your choice. No GeForce Experience, no accounts with NVIDIA, no trips to the
website.

### Features
- Automatic GPU detection - single, dual, desktop or laptop NVIDIA GPUs
- Checks daily or weekly and grabs the latest Game Ready or Studio driver
- Silent background install (one-time admin approval) or notify-then-click
- Clean driver-only install - skips the GeForce Experience bloat
- Runs quietly in the system tray; opens to a simple status + settings panel
